<h1>🧱 Brick Breaker Game</h1>
<p>
  A simple <b>Brick Breaker game</b> built with HTML, CSS and JavaScript<br>
  Control the paddle, bounce the ball, and break all the bricks!
</p>
▶ <a href="https://adamfeher3.github.io/brick-breaker/">Play the game!</a>
<h2>🕹 How to play</h2>
<p>
  Use <b>A, D</b> or <b>Left</b> and <b>Right Arrows</b> to control the paddle<br>
  Press <b>SPACE</b> to start the ball<br>
  Press <b>P</b> or <b>ESC</b> to pause/resume the game
</p>
